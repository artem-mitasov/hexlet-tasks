Протестируйте функцию reverse() с длинным текстом. Эта функция принимает любую строку, возвращает новую перевернутую строку.

# Эта функция переворачивает переданную строку
def reverse(string):
    return string[::-1]
Используйте знания, изученные в уроке и создайте необходимые данные. У вас должны получиться как минимум два файла - один для входных данных (исходный текст) и файл с результатом (перевернутая строка).
